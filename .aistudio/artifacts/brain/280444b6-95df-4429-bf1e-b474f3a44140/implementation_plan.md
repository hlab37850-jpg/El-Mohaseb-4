# تطبيق محاسبة ومخازن (محاسب سوفت - Mohaseb Soft)

تطبيق متكامل لإدارة الحسابات والمخازن مبني باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3** وبنية **Clean Architecture / MVVM** مع قاعدة بيانات **Room** للتخزين المحلي الدائم، متطابق بدقة هندسية وبصرية مع تصميم وواجهات تطبيق "محاسب سوفت" المعروض بالفيديو المرفق.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **القرارات المؤكدة من المستخدم:**
> 1. **لغة وبيئة العمل**: بناء التطبيق بنظام Android باستخدام **Kotlin & Jetpack Compose** لتحقيق أعلى أداء وسلاسة، مع مطابقة الواجهات وتجربة المستخدم للفيديو بدقة.
> 2. **التخزين وقاعدة البيانات**: **تخزين محلي (Local Room Database)** مع جداول مهيكلة وعمليات غير متزامنة (Coroutines & Flow) لضمان العمل التام بدون إنترنت بسرعة وموثوقية فائقة.
> 3. **نطاق الموديولات**: تنفيذ كافة الموديولات والشاشات الأساسية (المبيعات، المشتريات، القبض والصرف، العمليات المخزنية، قيود الحسابات، إدارة الأصناف، العملات، وشاشات التقارير والقائمة الجانبية).

---

### 1. Overview & Core Concept

- **الهدف الرئيسي**: تزويد أصحاب المتاجر والمستودعات بنظام محاسبي ومخزني سريع وسلس لإصدار فواتير المبيعات والمشتريات، وتتبع الأرصدة، وسندات الصرف والقبض، والتحويلات والتسويات المخزنية، ومتابعة الأرباح وحركات الأصناف.
- **الفئة المستهدفة**: المحاسبون، أمناء المخازن، أصحاب المشاريع الصغيرة والمتوسطة، ومندوبو المبيعات.
- **القيمة المضافة**: واجهة عربية أصيلة معتمدة على مبادئ RTL الطبيعية، تصميم كلاسيكي أزرق عصري مطابق لـ "محاسب سوفت"، وأداء فوري بدون تعليق مع دعم المعاملات النقدية والآجلة وتعدد العملات والمخازن.

---

### 2. User Experience & Visual Design

#### Visual Identity & Color Palette
- **اللون الأساسي (Primary)**: تدرجات الأزرق المحاسبي العريق والمهني (`#0D62A8` و `#1565C0`) للشريط العلوي وقوائم الأكورديون.
- **أزرار الشبكة السريعة (Quick Action Grid Cards)**: بلاطات متدرجة بلون فيروزي-أزرق ساطع (`#00838F` إلى `#0097A7` أو `#0288D1`) مع أيقونات بارزة وزر إضافة دائري بلون كحلي داكن (`#004D40` / `#0D47A1`).
- **لون الخلفية (Background)**: رمادي فائق النعومة (`#F5F7FA`) لراحة العين والتباين الأمثل مع البطاقات البيضاء.
- **السطوح والبطاقات (Surfaces)**: كروت بيضاء ناصعة (`#FFFFFF`) مع ظلال ناعمة (Elevation 2dp) وزوايا منحنية (12dp).
- **ألوان المؤشرات المالية**:
  - مدين / وارد / أرباح: أخضر زمردي (`#2E7D32`)
  - دائن / منصرف / خسائر: أحمر مرجاني (`#C62828`)
  - تنبيهات وملاحظات: برتقالي دافئ (`#EF6C00`)

#### شاشات وتدفقات المستخدم الرئيسية (User Flows)
1. **الشاشة الرئيسية (Dashboard)**:
   - **شريط علوي (TopAppBar)**: زر القائمة الجانبية (Drawer)، عنوان التطبيق "محاسب سوفت"، جرس التنبيهات مع مؤشر، وزر المشاركة.
   - **الشبكة السريعة (2x2 Grid)**:
     - **المبيعات** (+ زر إضافة فاتورة فورية)
     - **المشتريات** (+ زر إضافة فاتورة شراء فورية)
     - **قبض / صرف** (مع أيقونة السندات)
     - **الحسابات** (مع أيقونة دليل الحسابات)
   - **القوائم المنسدلة (Expandable Accordion Sections)**:
     - **عمليات مخزنية**: صرف مخزني، توريد مخزني، تحويل مخزني، تسوية مخزنية، إضافة مخزن، جرد مخزني.
     - **قيود وحسابات**: قيد يومي، قيد إفتتاحي، إضافة حساب، حركة الصندوق، دليل الحسابات، إقفال سنوي.
     - **أصناف**: الأصناف، أسعار البيع، وحدات الصنف، فاتورة عرض سعر، طلب شراء.
     - **العملات**: العملات، إضافة عملة، سعر العملات، سقف الحساب.
     - **التقارير**: حركة الأصناف، ميزان المراجعة، قائمة الدخل، المركز المالي، تقارير أخرى.
   - **الشريط السفلي (Bottom Status Bar)**:
     - زر يوتيوب التعليمي، مؤشر المخزن الحالي النشط ("المخزن الرئيسي")، وزر التبديل/التحديث.
2. **شاشة الفواتير (بيع آجل / نقدي / مرتجع & شراء)**:
   - تبديل نوع الدفع (آجل / نقد)، وتحديد مرتجع (مرتجع بيع / شراء).
   - اختيار المخزن والعملة (محلي / دولار) والتاريخ واسم العميل/المورد.
   - جدول البنود الديناميكي مع حوار إدخال سريع للصنف، الكمية، السعر، أو الإجمالي مع حاسبة سريعة.
   - شريط إجمالي الفاتورة السفلي (الصافي، الخصم، الضريبة، الرسوم، المبلغ المدفوع والمتبقي)، وزر الحفظ.
3. **شاشة السندات (سند قبض / سند صرف)**:
   - خيار التحويل بين قبض وصرف، تحديد الصندوق أو الحساب، المبلغ، الملاحظات، وخيار العملة.
4. **شاشات العمليات المخزنية والحسابات والتقارير**:
   - شاشات عرض البيانات وجداول ملخصة وقوائم تفصيلية مع فلاتر البحث وإمكانية الإضافة.
5. **القائمة الجانبية (Navigation Drawer)**:
   - خيارات النسخ الاحتياطي، جوجل درايف، دليل الحسابات، الإعدادات، ومعلومات التطبيق.

### 3. Key Product Decisions & Trade-Offs

- **الاعتماد على Jetpack Compose**:
  - *القرار*: بناء الواجهات بالكامل عبر Compose بأسلوب Declarative لضمان الأداء السلس والتفاعل الفوري المريح، ومطابقة واجهات الفيديو وألوانه بكل دقة.
  - *البديل*: تم استبعاد الأطر الوسيطة لضمان استقرار البناء والتكامل الفوري مع بيئة التشغيل السحابية في Android Studio Build.
- **التخزين المحلي باستخدام Room**:
  - *القرار*: استخدام Room مع KSP و SQLite محلي لضمان تخزين فوري، عمل بدون انقطاع وبدون إنترنت، مع توفير عينات بيانات أولية واقعية (أصناف، عملاء، مخازن، فواتير تجريبية) لتبدو كل الشاشات نشطة وتفاعلية منذ أول تشغيل.
  - *البديل*: تم استبعاد التخزين السحابي المؤقت بناءً على اختيار المستخدم الصريح للتخزين المحلي.
- **التنقل المخصص (Custom State & Jetpack Navigation)**:
  - *القرار*: إدارة التنقل مع `BackHandler` متكامل للعودة السلسة للشاشة الرئيسية وحفظ حالة الشاشات، ودعم كافة المسارات المسمّاة (Named Routes).

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Jetpack Compose UI Layer                        │
│                                                                        │
│   TopAppBar & Drawer ──► Main Dashboard Screen ◄── Bottom Status Bar   │
│                                │                                       │
│          ┌─────────────────────┴──────────────────────┐                │
│          ▼                                            ▼                │
│   Quick Action Grid (2x2)               Accordion Expansion Tiles      │
│   - Sales (+ / List)                    - Warehouse Operations         │
│   - Purchases (+ / List)                - Journal Entries & Accounts   │
│   - Vouchers (Receipt / Payment)        - Items & Price Lists          │
│   - Accounts Directory                  - Currencies & Rates           │
│                                         - Reports & Financials         │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        MVVM State Layer                                │
│   AccountingViewModel (StateFlow, Invoices, Vouchers, Items, Accounts) │
└────────────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Repository & Room DB Layer                      │
│                                                                        │
│   Entities: Account, Item, Warehouse, Invoice, InvoiceItem, Voucher    │
│   DAO: AccountingDao (Flow<List<...>>, suspend insert/update/delete)   │
│   Database: MohasebDatabase (Pre-populated SQLite local DB)            │
└────────────────────────────────────────────────────────────────────────┘
```

#### خطة الكيانات (Room Entities)
1. `AccountEntity`: رقم الحساب، اسم الحساب، نوع الحساب (أصول، التزامات، مصروفات، إيرادات)، الرصيد، العملة، الهاتف، العنوان.
2. `ItemEntity`: كود الصنف، اسم الصنف، مجموعة الصنف، الوحدة، سعر الشراء، سعر البيع، الكمية المتوفرة بالمخزن.
3. `WarehouseEntity`: رقم المخزن، اسم المخزن، العنوان، الهاتف.
4. `InvoiceEntity`: رقم الفاتورة، نوعها (مبيعات / مشتريات)، حالة الدفع (نقدي / آجل)، مرتجع (نعم/لا)، التاريخ، العميل/المورد، الإجمالي، الخصم، الضريبة، المدفوع، المتبقي.
5. `InvoiceItemEntity`: معرف الفاتورة، كود الصنف، اسم الصنف، الكمية، السعر، الإجمالي.
6. `VoucherEntity`: رقم السند، نوع السند (قبض / صرف)، الحساب/الصندوق، المبلغ، العملة، البيان/الملاحظات، التاريخ.
7. `CurrencyEntity`: اسم العملة، الرمز، الفكة، سعر الصرف بالنسبة للمحلي.

### 5. خطة مراحل التنفيذ (Step-by-Step Implementation Roadmap)

- [ ] **المرحلة 1: تهيئة الهوية وقاعدة البيانات المحلية (Database & Core Setup)**
  - تحديث `metadata.json` و `strings.xml` لاسم التطبيق "محاسب سوفت" (Mohaseb Soft).
  - ضبط ألوان وثيمات التطبيق في `Color.kt` و `Theme.kt` بالدرجات الزرقاء والأشكال الدقيقة.
  - إنشاء كيانات Room وقواعد البيانات و DAO و Repository مع عينات بيانات أولية حقيقية.
- [ ] **المرحلة 2: إنشاء ViewModel ومنطق العمليات المحاسبية والمخزنية**
  - بناء `AccountingViewModel` لإدارة الفواتير، الحسابات، سندات الصرف والقبض، وحركات المخزن وإحصائيات التقارير.
- [ ] **المرحلة 3: بناء الشاشة الرئيسية (Main Dashboard Screen)**
  - شريط علوي مع زر Drawer وقائمة الإشعارات والمشاركة.
  - شبكة الأزرار الأربعة (المبيعات، المشتريات، القبض/الصرف، الحسابات) مع أزرار الإضافة السريعة.
  - القوائم المنسدلة الخمس بالألوان الزرقاء الأنيقة كما بالفيديو.
  - الشريط السفلي بحالة المخزن الحالي وزر الانتقال السريع.
  - القائمة الجانبية (Navigation Drawer) الكاملة.
- [ ] **المرحلة 4: بناء الشاشات التفاعلية والحوارات المنبثقة (Sub-Screens & Modals)**

  - شاشات العمليات المخزنية (توريد، صرف، تحويل، تسوية، جرد).
  - شاشات دليل الحسابات وقائمة الأصناف والعملات.
  - شاشات التقارير المالية (حركة الأصناف، ميزان المراجعة، الأرباح، قائمة الدخل).
- [ ] **المرحلة 5: التحقق والبناء (Verification & Build Check)**
  - تشغيل `compile_applet` للتأكد من خلو المشروع من أية أخطاء تجميع، وضمان عمل التطبيق بسلاسة تامة.
